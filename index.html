Interpretab

브라우저 탭 소리와 내 마이크를 Gemini로 실시간 통역해 음성과 자막으로 들려줍니다. 내 목소리를 상대 언어로 보낼 수도 있습니다.

タブ音声とマイクを Gemini でリアルタイム通訳し、音声と字幕で届けます。自分の声を相手の言語で送ることもできます。

  • 중간 서버 없이 내 키로 Gemini에 직접 연결中継サーバーなし、自分のキーで Gemini に直接接続

사용법

使い方
A

이음 LIVE

  1. 자막 링크 받기

    당일 운영진이 자막 링크(또는 QR·자막 코드)를 보내 드립니다.

    字幕リンクを受け取る

    当日、運営から字幕リンク（またはQR・字幕コード）をお送りします。

  2. 링크 열기

    휴대폰이나 다른 창에서 엽니다. 가입·설치·마이크 권한이 필요 없습니다.

    リンクを開く

    スマホや別ウィンドウで開きます。登録・インストール・マイク許可は不要です。

  3. 언어 선택

    한국어 또는 일본어를 고르면 원문과 번역이 한 줄에 나옵니다. 글자 크기·고대비도 바꿀 수 있습니다.

    言語を選ぶ

    韓国語または日本語を選ぶと、原文と翻訳が同じ行に表示されます。文字サイズ・ハイコントラストも変更できます。

B

Interpretab

처음 설정은 약 5분입니다. 연수 전날까지 해 두세요.初回設定は約5分です。研修の前日までに済ませてください。

↓Chrome에 확장 프로그램 설치Chrome に拡張機能を追加chromewebstore.google.com · Interpretab↗
  1. 확장 프로그램 설치

    위 버튼으로 Interpretab을 추가하고 툴바에 고정합니다. PC Chrome에서만 됩니다.

    拡張機能をインストール

    上のボタンから Interpretab を追加し、ツールバーにピン留めします。PC版 Chrome のみ対応。

  2. Gemini API 키 만들기

    Google AI Studio에서 무료 키를 만듭니다. 처음이면 Google Cloud 프로젝트도 함께 생깁니다.

    Gemini API キーを作成

    Google AI Studio で無料キーを作成します。初回は Google Cloud プロジェクトも作成されます。

  3. 키 붙여넣기

    확장 옵션에 키를 넣고 Free/Paid를 고릅니다. 키는 내 컴퓨터에만 저장됩니다.

    キーを貼り付け

    拡張機能の オプション にキーを入れ、Free / Paid を選択。キーは自分のPCにのみ保存されます。

  4. 회의 탭에서 시작

    회의 탭에서 아이콘 클릭(권한 허용) → 사이드 패널에서 언어 선택 → Start

    会議タブで開始

    会議タブでアイコンをクリック（権限を許可）→ サイドパネルで言語選択 → Start

  5. 모드 고르기

    듣기: 탭 오디오 → 한국어. 화면 아래 자막 3줄.
    말하기: 마이크 → 동시통역 또는 양방향 대화.

    モードを選ぶ

    聞く：タブ音声 → 日本語。画面下に字幕3行。
    話す：マイク → 同時通訳または双方向会話。

  6. Meet에서 내 목소리 보내기 (선택)

    헤드폰 착용 → 탭 오디오는 상대 언어, 마이크는 내 언어 → Meet 마이크를 Interpretab (translated)로 선택

    Meet で自分の声を送る（任意）

    ヘッドホン着用 → タブ音声は相手の言語、マイクは自分の言語 → Meet のマイクを Interpretab (translated) に

알아 두세요
  • 기계 번역이라 이름·전문용어를 잘못 들을 수 있습니다.
  • 마이크를 쓸 땐 헤드폰이 필요합니다. 스피커면 소리가 되돌아갑니다.
  • 한 번에 한 탭만 통역됩니다. 탭 오디오와 마이크를 함께 쓰면 비용이 2배입니다.
  • 무료 키는 Google이 데이터를 제품 개선에 쓸 수 있습니다. 키는 공유하지 마세요.
  • Zoom·Teams로 내 목소리를 보내려면 BlackHole·VB-Cable 같은 가상 오디오 장치가 필요합니다.
ご注意
  • 機械翻訳のため、名前や専門用語を聞き間違えることがあります。
  • マイク使用時はヘッドホンが必要です。スピーカーだと音が回り込みます。
  • 通訳は一度に1タブのみ。タブ音声とマイクを同時に使うと費用は2倍です。
  • 無料キーでは Google がデータを製品改善に使う場合があります。キーは共有しないでください。
  • Zoom・Teams で自分の声を送るには BlackHole・VB-Cable などの仮想オーディオが必要です。

研修後も続く交流

연수 당일뿐 아니라 그 뒤에도 선생님들이 계속 교류할 수 있도록 한·일 선생님을 위한 교류 공간을 만들었습니다.

研修当日だけでなく、その後も先生同士で交流を続けられるよう、日韓の先生向けの交流スペースを作りました。

  • 한국어·일본어 자동 번역 日本語・韓国語の自動翻訳각자의 언어로 일상과 수업 아이디어를 편하게 나눕니다.それぞれの言語で、日常のことや授業のアイデアを気軽に話せます。
  • 교류 수업 상대 학교 찾기 交流授業の相手校探し학교끼리 교류 수업을 해 보고 싶은 선생님은 상대 학교를 찾아 연결할 수 있습니다.学校同士で交流授業をしてみたい先生は、相手校を探してつながれます。
  • 바로 참여 すぐに参加로그인한 뒤 학교 정보와 자동 번역 동의를 확인하면 바로 참여할 수 있습니다.ログインして学校情報と自動翻訳への同意を確認すれば、すぐに参加できます。
